# 09 優れたUIデザイン 実例カタログ（Reference Catalog）

> **重要:** このカタログは「リンク＋なぜ優れているかの言語化」のみを目的とします。画像やコードのコピーは行いません。各サイトは公開ドキュメント・公式サイトの**閲覧・参照**にとどめ、ギャラリー系サービスの規約に反するスクレイピングは行わないでください。

## 使い方

このカタログは眺めて終わりにするものではなく、**「観察 → 言語化」の反復トレーニング教材**として使います。おすすめは、毎日ランダムに3つのエントリを開き、実物のUIを見ながら「なぜこれが良いのか」を自分の言葉で1〜3文に書き出す習慣です。余白の取り方、タイポの階層、色数の絞り込み、情報密度、コンポーネントの一貫性——観点を1つに絞って観察すると精度が上がります。慣れてきたら「盗めるポイント」を実際に自分の制作物へ1つ移植し、Before/Afterで効果を検証します。デザインの上達は「良し悪しを見分ける眼」と「なぜを説明できる語彙」でほぼ決まるため、この言語化の積み重ねが最短ルートになります。収録は6ジャンル横断で60件以上。飽きたらジャンルを切り替えてください。

## 補足: 観察の観点チェックリスト

眺めるときは以下のどれか1つに絞ると、言語化の精度が上がります。

- **余白（Spacing）** … 要素間・セクション間のリズムは一定か。詰まりすぎ/空きすぎていないか。
- **タイポ（Typography）** … 見出し〜本文〜補助の階層は何段階か。行間・字間・ウェイトの使い分けは？
- **色（Color）** … 使用色は何色か。アクセントは何に使われているか。色だけで意味を伝えていないか。
- **階層（Hierarchy）** … 最初に目が行く場所はどこか。視線誘導は設計されているか。
- **密度（Density）** … 情報量は適切か。ターゲット（初心者/プロ）に合っているか。
- **一貫性（Consistency）** … 同じ役割の要素は同じ見た目か。角丸・影・余白のルールは統一されているか。
